# 🕵️ Thief Escape — Don't Get Caught!

**Thief Escape** is a lightweight, browser-based playable ad game built with **HTML, CSS, and Vanilla JavaScript**.

The player takes the role of a thief inside a secured museum. The objective is to **collect the key, steal the diamond, avoid the security guard's red vision, and escape through the exit**.

The game features multiple levels with progressively harder security, making the gameplay challenging and engaging.

## 🎮 Gameplay

Your mission is simple:

**🔑 Get the Key → 💎 Steal the Diamond → 🚪 Escape**

But be careful — the security guard continuously patrols the museum and can detect the thief when he enters the guard's vision.

### How to Play

1. Click **START HEIST**.
2. Move the thief using **mouse/touch drag** or **keyboard controls**.
3. Stay behind obstacles and hiding spots to avoid the guard.
4. Collect the **key** to unlock access to the diamond.
5. Collect the **diamond**.
6. Reach the **EXIT** to complete the level.
7. Avoid getting caught by the security guard.

The game contains **10 levels** with increasing difficulty.

|     2 | Easy        |
|     3 | Medium      |
|     4 | Medium      |
|     5 | Medium      |
|     6 | Hard        |
|     7 | Hard        |
|     8 | Hard        |
|     9 | Very Hard   |
|    10 | Final Heist |

As the levels progress, the security guard becomes faster and more difficult to avoid.
